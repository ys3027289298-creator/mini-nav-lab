# budget

1 ms 帧预算下的 A\* 扩展节点上限与降级策略，512×512 四邻域网格。

## 构建与运行

```
make test          # 编译并运行，自测失败时返回非零
python3 scripts/plot.py   # 从 results/*.csv 生成三张图
```

输出：`results/queries.csv`（600 条逐查询数据）、`results/summary.csv`（三档汇总）、
`results/over_budget.csv`（每个超预算查询的扩展数与所选降级方式）、
`results/run.log`（key=value 文本汇总）、`results/fig{1,2,3}_*.png`。
随机地图与迷宫均用固定种子，结构结果逐次运行完全一致；只有计时随机器负载浮动。

## 1. 扩展节点数关系式与上下界

记曼哈顿起终点距离 `d`、地图边长 `L=512`、障碍密度 `ρ`、四邻域 A\*（二叉堆 +
tie-break 偏向更大 g，使等值面尽量薄）的扩展节点数为 `E(d, ρ)`。

**下界（空旷，ρ→0，路径接近直线）**：启发式几乎不犯错，扩展只发生在
连接起止点的一条窄等值带上，

```
E_min(d, ρ) ≈ w(ρ)·d，  w(0) ≈ 1～4
```

实测空旷档近距桶 `E/d ≈ 3.5`（`run.log` 的 `expansion_vs_distance`）。

**上界（迷宫状，ρ≈0.5，启发式信息失效）**：曼哈顿启发式无法区分大量绕行节点，
搜索退化为按 g 值的广度填充，最坏扩展到连通分量的全部可走格，

```
E_max ≤ N_free(ρ) = (1−ρ)·L² = (1−ρ)·262144
```

本迷宫可走率恰好 0.5，实测 `exp_max=130939 ≈ N_free=131072`，即上界被真实触达；
近距桶 `E/d` 高达 430——目标再近也要填掉半个分量。

中间形态（随机障碍 ρ=0.10/0.25）介于两者之间，随 d 亚线性增长后被连通分量封顶，
完整曲线见 `results/fig3_expansion.png`。

## 2. 从 1 ms 预算反解扩展上限

先在本机实测单节点成本 `c = 耗时 / 扩展数`（仅取扩展 ≥200 的查询，排除小查询的
时钟噪声）。600 次查询的汇总均值约 65 ns/节点，但分档看随机障碍图约 125 ns/节点、
迷宫约 65 ns/节点——**用全局均值反解会让 dense 档系统性超时**。因此取池内 p95
作为保守单节点成本，并给游戏逻辑留 20% 余量（只花 800 µs 在寻路上）：

```
cap = 0.8 × 1000000 ns / c_p95
```

本次运行 `c_p95 ≈ 161 ns/节点 ⇒ cap ≈ 4981`（多机次运行区间约 4600～5000；
均值口径会给出 ~12000，已在 `run.log` 同时打印 `cap_mean_based` 作对照）。
窗口半径按 `(2r+1)² ≤ cap` 反解，得 `r ≈ 34`。

## 3. 降级策略：用两条曲线定夺

两种降级各有代价，用 600 条查询实测的**寻路成功率**与**平均路径误差**两条曲线选择
（图 `fig1_success.png`、`fig2_error.png`；路径误差 = 粗路径各点到全量 A\* 最优
路径的 BFS 距离场均值，单位格）。

| 方案 | 成功率曲线说的话 | 误差曲线说的话 |
|---|---|---|
| 缩短搜索半径（窗口细粒度 A\*） | 目标在窗外即失败：r=256 时随机图也只有 ~0.46，迷宫仅 0.24 | 成功时**误差为 0**（窗口内仍是精确 A\*） |
| 粗粒度块图 A\*（B=8，64×64=4096 节点） | 随机图 1.00；迷宫 0.94（多数阈值建图，见下） | 随机图中位偏差 12/33 格；迷宫中位 2334 格且仅 3% 段有细图视线，不可直接平滑 |

结论（实现于 phase 2）：

1. `E ≤ cap`：跑全量细粒度 A\*，精确路径；
2. 超预算且切比雪夫距离 `≤ r`：**窗口细粒度 A\***，精确、零误差；
3. 否则走 **B=8 粗粒度块图**（整张图 4096 节点 < cap，最坏也在预算内），
   块中心连线作为航点，再交 `smooth/` 模块做贪心视线平滑；
4. 粗图因连通性失败（迷宫中 6%）：退回带 cap 的窗口搜索，给出朝目标推进的
   **部分路径**，下一帧继续，保证单帧永不超预算。

粗图建图规则：块内障碍格严格过半才标记阻塞。「任一格阻塞即整块阻塞」的悲观规则
在 ρ=0.25 时会让 8×8 块全空概率降到 ~10⁻⁸、粗图几乎全黑（成功率 0），多数阈值
保留连通性，误差再由 BFS 距离场量化。

## 4. 三档结果（每档 200 条分层距离查询）

扩展数、成功率、误差为固定种子下的确定值；全量 A\* 超 1ms 占比依赖机器计时，
给出多次运行的观察区间：

| 档位 | 实际 ρ | 扩展 p50 / p95 / max | 全量 A\* 超 1ms 占比 | 粗图成功率 / 中位误差(格) |
|---|---|---|---|---|
| 稀疏随机 | 0.0998 | 2715 / 12485 / 52256 | 23～32 / 200 | 1.00 / 12 |
| 稠密随机 | 0.2493 | 6471 / 28365 / 61649 | 84～91 / 200 | 1.00 / 33 |
| 完美迷宫 | 0.5000 | 74059 / 125332 / 130939 | 163～170 / 200 | 0.94 / 2334 |

phase 2 每次约 360 条查询超过 cap：窗口 4 条、粗图约 330 条、部分路径 27 条；
**降级后最大单次耗时约 430 µs，无一超过 1 ms**（`degraded_over_1ms=0`，
逐查询的扩展数与方式见 `results/over_budget.csv`）。

迷宫档的粗路径误差大是结构性的：块中心偏离 1 格宽的走廊，粗路径只适合做
高层航点，实际移动仍需沿航点做局部细粒度搜索/平滑，不能直接当行走路径。
