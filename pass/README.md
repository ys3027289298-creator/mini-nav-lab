# pass

体型感知的通行性判定，替代旧文档「统一半径 0.3 m」的单判据。`make test` 跑自检，
全部断言通过时退出码为 0。

## 1. 三个判据（同时满足才可通行）

角色以碰撞半径 `r`、地面摩擦系数 `μ`、设计速度 `v` 描述，通道取途中最窄宽度
`W* = min_k W_k`，坡面角 `α`，路径弯曲半径 `R_b`：

| 判据 | 表达式 | 物理含义 |
|---|---|---|
| 通道宽度 | `W* ≥ 2r` | 直径（两倍半径）放得下 |
| 斜坡角度 | `tan α ≤ μ`，即 `α ≤ arctan μ` | 摩擦力 ≥ 重力沿坡分量 |
| 转弯半径 | `R_b ≥ v² / (μg)` | 侧向摩擦力提供向心力 `mv²/R_b ≤ μmg` |

任一不满足即不可通行；宽度判据还需区分「进不去」和「进去后卡住」（见第 3 节）。

## 2. 三档体型与反解阈值

实测体型参数（旧文档的 0.3 m 保留为中档 M）：

| 档位 | 角色 | r (m) | μ | v (m/s) |
|---|---|---|---|---|
| S | 小型宠 | 0.15 | 0.9 | 4.0 |
| M | 贴墙滑行角色 | 0.30 | 0.7 | 6.0 |
| L | 大型怪 | 0.80 | 0.5 | 3.0 |

代入三个判据反解（g = 9.81）：

| 档位 | W_min = 2r (m) | α_max = arctan μ | R_min = v²/(μg) (m) |
|---|---|---|---|
| S | **0.300** | **41.99°** | **1.812** |
| M | **0.600** | **34.99°** | **5.242** |
| L | **1.600** | **26.57°** | **1.835** |

注意三个阈值不是同增同减：L 档宽度要求最苛刻，M 档因速度高转弯要求最苛刻，
S 档三项都最宽松。这正是单一半径判据无法覆盖的原因。

## 3. 临界状态：卡住判别式

入口宽度介于半径与直径之间（`r < W* < 2r`）时，角色正面能挤进缺口，但圆形
碰撞体在最窄处两侧各需 `r` 的净空，总和 `2r > W*`，于是中途卡死。

定义比值

```
ρ = W* / r
```

判别区间：

- `ρ ≤ 1`：**NO_ENTRY**，入口就进不去；
- `1 < ρ < 2`：**STUCK**，挤得进去、在最窄处卡住；
- `ρ ≥ 2`：宽度判据通过，再查斜坡与转弯。

自检的 30 个体型×通道组合中 STUCK 共 6 例（S-C5、M-C3、M-C4、L-C2、L-C6、
L-C8），与实测夹具逐格一致。

## 4. 贴墙滑行的速度效应与绕行预生成

贴墙滑行时离心效应把有效碰撞包络向外推，建模为速度平方项：

```
r_eff(v) = r0 + kc·v²          kc = 1/240 s²/m
W_min(v) = 2·r_eff(v) = 2r0 + 2kc·v²
```

`kc` 由标定锚点确定：M 档在设计速度 v_max = 6 m/s 时有效半径增大 50%
（0.30 → 0.45 m），故 `kc = 0.5·r0 / v_max² = 1/240`。

反解给定通道的安全速度：

```
v_max(W) = sqrt( (W/2 − r0) / kc )
```

6 m/s 下 M 档的可通行宽度门槛由静态 0.60 m 升到 **0.90 m**。对静态可通行的
通道逐条核算：

| 通道 | W* (m) | 静态判定 | v_max (m/s) | 6 m/s 结论 |
|---|---|---|---|---|
| C1 | 2.00 | PASS | 12.96 | ok |
| C9 | 1.70 | PASS | 11.49 | ok |
| C8 | 0.85 | PASS | 5.48 (=√30) | **DETOUR** |
| C10 | 0.62 | PASS | 1.55 (=√2.4) | **DETOUR** |

**需要提前生成绕行的通道编号：C8、C10。** 两者静态判定都是 PASS，只有速度
关系式能识别出高速不可通行，因此绕行路径必须在离线路径规划阶段预生成，不能
等到角色卡在墙面上再重算。

## 5. 分档取舍：两条曲线

在同一批 30 个组合上比较三种方案，维护量按每档参数数（r、μ、v）计：

| 方案 | 窄通道误判数（W*<1 m，共 18 例） | 全集误判数（30 例） | 维护参数量 |
|---|---|---|---|
| 统一 1 档（全员 r=0.3） | **8** | 12 | 3 |
| 两档（S 并入 M） | **3** | 5 | 6 |
| 三档独立 | **0** | 0 | 9（+1 个 kc） |

误判曲线在 1→2 档下降 5、2→3 档再降 3 且窄通道归零；维护量曲线每档线性 +3。
窄通道误判的代价是角色实体卡死（运行时不可恢复），而参数维护是一次性成本，
两条曲线的交点落在三档：**采用三档独立参数**。统一方案的 8 个窄通道误判
主要是以 M 尺寸低估 L 档（C3/C4/C7/C8/C10 被误判可通行），不可接受。

## 6. 自检结果

`make test` 输出包含：三档阈值数值校验、30 格分类与实测夹具一致、STUCK 共
6 例、三方案误判数（8/3/0）、kc 标定与 C8/C10 绕行结论，全部 `=1`，
末行 `all_ok=1`。
