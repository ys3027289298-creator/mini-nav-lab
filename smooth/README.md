# smooth

`make test` 跑自检。

两个层次：

- **直线检测平滑**（原有）：bresenham/LOS 只拒绝穿过阻挡格的线段，等价于要求离墙距离 `d > 0`，即边距 0。
- **胶囊轮廓平滑**（新增）：把角色当作半径 `R` 的胶囊，路径按质心算。线段离墙距离为 `d` 时外沿越界量为
  `overrun = max(0, R - d)`；要求每条线段 `overrun = 0` 即要求 `d >= R`。平滑边距 `m` 正是 `d` 的下界，
  所以零越界 ⇔ `m >= R`，最小合法边距就是 `R`。

`make test` 的输出给出：

- 每个场景、三档体型（R = 0.25 / 0.35 / 0.45）下：
  - `legacy_viol` / `legacy_min_d` / `shortfall`：直线检测路径的越界段数、最小离墙距离、差 `R` 多少；
  - `safe_viol` / `safe_min_d`：胶囊平滑路径的越界段数与最小离墙距离；
  - `cstar`：用「越界次数为零」反解出的最小边距（= `R`，开放场景里原有路径已合法则为 0）；
  - `incr`：相对直线检测路径的长度增幅。
- `curve=...`：边距从 0 扫到 0.60 的「越界段数 / 路径长度」两条曲线，用来定边距。
- `budget_exceeded`：越界为零且长度增幅超过 5% 的场景数；超出的场景会打印
  `BUDGET ...` 行，给出边距取值与越界最严重的那一段（端点坐标与越界量）。

实现要点：以起点、终点和障碍角点处半径 `m` 的圆弧采样点建可见性图，Dijkstra 求最短路，再
polish（把顶点滑向其邻弦投影的可保持边距的最远位置）与 simplify（跳过可直连的中间点）。
圆弧图近似最优；在 16x12 测试场景中与稠密网格测地线相差 < 0.3%，耗时约 0.1 s。
