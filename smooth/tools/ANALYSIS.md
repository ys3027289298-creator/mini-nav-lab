## 1. 直线可达判据（视线检测）

格 b 是单位方块 `Q_b=[x,x+1]×[y,y+1]`，节点为格中心。线段
S = segment(p0,p1)，障碍集 B，角色半径 r：

```
                d(S, Q_b) = min_{u∈S, v∈Q_b} ‖u−v‖
LOS(p0,p1,r) ⇔  min_{b∈B} d(S, Q_b) > r
```

半径 r 的扫掠管与方块相交当且仅当 d ≤ r，故取**严格大于**（擦边视为
阻挡）。r=0 退化为"线段不得进入任何障碍格"。

`d(S,Q_b)` 精确解：f(t)=dist(P(t), Q_b)² 是分段二次函数，最小值只可能
出现在 t∈{0,1}、线段与方块四条面的交点参数、四个角点在线上的投影
参数。实现见 `smooth.c` 的 `seg_box_dist`；自检同时用 2048 点密采样
（`seg_clearance_sampled`）独立复核。

**旧实现失效根因**：Bresenham supercover 沿格心步进，斜线段会漏掉被
实际穿过的格。中心线 (0.5,0.5)→(12.5,7.5) 穿过 (4,3)、(9,6)，
Bresenham 均未访问 → 墙"不存在" → 任何弦都通过 LOS → 平滑输出等于
原路径。自检用例 `bresenham_misses_pillars=1` /
`exact_los_catches_pillars=1` 锁定该差异。

## 4. 两条曲线与强度选择

| r | 点数 | 折线长度 | 最小间隙 |
|---|---|---|---|
| 0.00 | 3 | 14.0384 | 0.0767 |
| 0.10 | 3 | 13.9789 | 0.1387 |
| 0.20 | 3 | 13.9875 | 0.2325 |
| 0.25 | 4 | 14.0623 | 0.3000 |
| **0.35** | **4** | **14.1241** | **0.4856** |
| 0.50 | 4 | 14.0530 | 0.5582 |

- 点数是非降阶梯（3→4），长度在 13.98–14.12 间小幅交换，间隙随 r
  单调改善；r=0 的 3 点方案虽最短，但 0.077 格的擦角余量对任何有半径
  的角色都会卡住。
- 选 **r=0.35**：仍处于 4 点平台、间隙裕度最大（0.486 格），且长度
  惩罚可忽略。
