# reconcile

可走格计数（布尔为真）与洪水填充计数（被访问/填充事件）的对账工具。
纯标准库；`tradeoff.py` 额外需要 `matplotlib`。

```sh
make test       # 镜像自检 + 三个注入实验 + 340/352 重构，全部要求 formula_error=0
make exp-u      # 孤立格     -> U（未被访问的可走格）
make exp-o      # 边界贴边   -> O（越界却被计数的访问）
make exp-r      # 重复填充   -> R（同一格被重复计数）
make mystery    # 340 vs 352 反解 + 坐标转储 + 未覆盖项 K
make tradeoff   # 生成 artifacts/reconcile-tradeoff.{csv,png}
```

## 对账前先声明统计口径

1. 唯一地图快照（脚本打印 blocked 位图的 sha256 前 12 位）；两个计数必须来自同一快照。
2. `W` = 界内 `blocked == 0` 的格数。
3. `V` = 被审计的填充实现返回的原始标量；这里按题意把它定义为“填充事件数”，
   **不是** `region.c` 返回的连通分量 id 个数 `next`。若 352 字面指 `next`，
   则在同一口径下 `分量数 ≤ 可走格数`，352 > 340 直接不可能。
4. 播种范围：all-scan（`region.c` 外层扫描，每个未访问格都播种）还是
   main-region（只从声明的起点填主区域）。墙内孤立区域在 main-region 口径下
   属于 `U`，两边本来就不该相等。

## 公式

每个 `V` 的 `+1` 都必须产生一个原始 `(x,y)` 事件，审计器独立分类：

- `good`：界内可走格的首次事件
- `R`：该可走格的后续重复事件
- `O`：越界坐标事件
- `K`：界内阻挡格事件（三公式未覆盖项）
- `U = W - good 数`：没有首次事件的可走格
- `L = V - 事件总数`：标量与台账不符的黑账项

于是恒等式：

```
V - W = R + O + K - U + L
```

题目要求的三项式是 `K = L = 0` 的特例：`D = R + O - U`。

整数恒等，实验通过标准是 `formula_error == 0`。预测不等于实测时，脚本转储
多算/漏算坐标：阻挡却被计数的格、重复事件坐标、越界坐标、未访问可走格。

## 真实 340/352 地图怎么办

仓库里没有产生 340/352 的那张图，两个标量本身不足以恢复十二个坐标，也不能
唯一指认缺失项（可能是 `K`，也可能是快照/口径项 `S`：两次计数用了不同地图
版本或不同尺寸）。在真实填充代码（如 `region/src/region.c`）里，`comp[]`
已经是每格标记，对账只需在填充后加一次集合 diff：

```c
for (int i = 0; i < W*H; i++) {
    int x = i % W, y = i / W;
    if (comp[i] >= 0 && m.blocked[i])      printf("over_counted (%d,%d)\n", x, y); /* K */
    if (!m.blocked[i] && comp[i] < 0)      printf("unvisited_walkable (%d,%d)\n", x, y); /* U */
}
```

同时核对两次计数输入地图的哈希/尺寸，排除快照口径项 `S`。
`reconcile.py mystery` 用一张 22×16、12 个稀疏柱子的重构地图精确复现
`W=340, V=352`，演示“三项式误差 −12 → 坐标转储 → 发现 K=12 → 扩展式误差 0”
的完整定位过程；那些坐标是重构结果，不是对未知真实地图的断言。

## 标记位取舍

见 `artifacts/reconcile-tradeoff.png` 与 `.csv`。候选集精度定义
`P = k / |候选格集合|`（三种方法召回均为 1）。12 个异常下：

- 每格 uint8 标记：`P = 1`，内存 `N` 字节（本仓库 192 B；340 场景 352 B）。
- 只比总数：候选集是全部 `N` 格，`P = 12/N`，1M 格时约 `1.1e-5`。
- 8×8 分块小计对比：精度约稳定在 `1/64`，小图上因块数太少几乎退化为总数对比。

结论：加。导航网格尺度下一字节/格的成本可忽略；`region.c` 本来就保留
`comp int[]`（4N 字节），其边际成本为零，只需把它暴露出来做 diff。
