# sizing

网格边长 h 的选型分析：用可表达性判据、误判率与节点数三条线定 h。

- `python3 -I sizing.py` 跑完整推导、数值反解与蒙特卡洛校验，结果打印到控制台并写入 `results/`
- `python3 -I make_chart.py` 读取 `results/*.csv` 生成自包含交互图 `chart.html`（浅色/深色、十字线 tooltip）

## 1. 输入与符号

| 符号 | 含义 | 文档值 |
|---|---|---|
| r | 角色半径 | 0.40 m |
| θ | 最大坡度 | 30° |
| h | 寻路网格边长（水平面） | 0.25 m |
| d | 角色能通过的最小窄缝宽度，d = 2r | 0.80 m |
| u | 缝左边界相对最近格线的相位 | u ~ U[0, h) |
| h_eff | 坡面上的最坏有效分辨率，h_eff = h / cosθ | 0.2887 m |

模型约定：

1. 窄缝按一维处理；角色圆能否通过只取决于缝宽是否 ≥ 2r。
2. 网格单元只有**整个单元落在缝内**才标记可走（保守栅格化，与 `grid/` 的二值可走性地图一致）。
3. 缝相对网格的相位均匀随机，所有“概率”都是对相位 u 取期望。
4. 坡度按最坏情形折算：坡面斜距每 h 米一个节点，有效分辨率变粗为 h/cosθ。

## 2. 可表达性判据：W/h > 2

缝宽 W、相位 u 下，完整落在缝内的单元数为

```
N(u) = max(0, floor((u+W)/h) − ceil(u/h))
```

对 u ∈ [0, h) 取期望，缝中至少保留 1 个完整可走单元的概率：

```
                ⎧ 0,          W/h < 1     （缝比单元还窄，任何相位都放不下完整单元）
P_open(W) =     ⎨ W/h − 1,    1 ≤ W/h < 2
                ⎩ 1,          W/h ≥ 2     （W=2h 仅对齐点例外，测度为零）
```

因此 **W/h ≤ 2 时存在把缝填掉的相位；W/h > 2 时对所有相位都可表达**。代入角色极限缝 d：

```
h < d/2 = r = 0.40 m
```

文档 h = 0.25 m 时 d/h = 3.20 > 2，判据达标，相对上限还有 37.5% 余量。

## 3. 两类误判都要能算

对任意缝宽 W，以 W ≥ d 为“真实可过”：

- **假阴性 FN（能过判成不能过）**：FN(W) = 1 − P_open(W)，仅 W ≥ d；
- **假阳性 FP（不能过判成能过）**：FP(W) = P_open(W)，仅 W < d。

在临界缝 W = d 处取最坏相位，误判率为

```
FN_worst = clip(2 − d/h, 0, 1) =
    0,       d/h ≥ 2
    2−d/h,   1 < d/h < 2     （h 越大线性恶化）
    1,       d/h ≤ 1         （临界缝被 100% 填掉）
```

## 4. 用误判率 ≤ 1% 反解 h 上限

### 口径 A：临界缝最坏相位（工程定标口径，推荐）

解 2 − d/h ≤ 0.01 得 h ≤ d/1.99 = **0.402 m**；硬性可表达判据 W/h>2 仍要求 h < **0.400 m**，
1% 预算只把硬边界放松 2 mm，实际起作用的是 h < 0.40 m。文档 0.25 m 在内。

### 口径 B：对缝宽分布取整体期望（更严格，用于暴露栅格化策略问题）

设场景缝宽 W ~ U[0, 2d]（脚本可改分布）。

- **朴素栅格化**：h→0 时整体误判率的结构性下限为 25%，全部来自假阳性——亚单元宽度的缝
  永远会被离散网格“打开”。该模型下 1% 预算**无解**，文档 h 处实测 26.56%。
- **按半径膨胀障碍（先腐蚀可走域再栅格化）**：假阳性结构性归零，整体误判只剩假阴性，
  工程区间（h ≤ d/2）闭式为 E[FN] = 3h/(4d)。1% 反解 h ≤ **0.0107 m**，
  对应节点数约为文档网格的 23² ≈ 530 倍，工程不可行。

结论：**“所有缝宽整体期望 1%”是过强口径**；可落地的定标方式是口径 A——保证角色实际
能遇到的最窄缝（W=d）在最坏相位下误判 ≤ 1%，即 h < 0.40 m。同时建议栅格化采用半径膨胀
策略消除假阳性（`smooth/` 的视线检测可复用同一腐蚀距离）。

所有闭式均由 50 万次/点的蒙特卡洛独立校验，工程区间偏差 ≤ 0.15 个百分点（见 `results/mc_check.csv`）。

## 5. 节点数曲线与可行区间

固定面积 A 下节点数 N = A/h²，相对文档网格：

```
N/N₀ = (h₀/h)²,   h₀ = 0.25
```

节点预算 N/N₀ ≤ 1.5 反推 h 的下限：

```
h ≥ h₀/√1.5 = 0.204 m
```

与误判上限联立，可行区间为 **h ∈ [0.204, 0.400) m**，文档 h = 0.25 位于区间内。
两条曲线（误判率随 h 单调上升、节点数比随 h 平方下降）的数据在 `results/curves.csv`，
交互图在 `chart.html`，阴影带即该可行区间。

## 6. 三约束各改一档的扫描结果

| 档位 | h_eff (m) | d/h_eff | W/h>2 | 临界缝最坏误判 | N/N₀ | 结论 |
|---|---|---|---|---|---|---|
| 基准 r=.40 θ=30° h=.25 | 0.289 | 2.77 | 是 | 0.00% | 1.00 | 达标 |
| 半径 +1 档 r=.50 | 0.289 | 3.46 | 是 | 0.00% | 1.00 | 达标（缝变宽反而更宽松） |
| 坡度 +1 档 θ=40° | 0.326 | 2.45 | 是 | 0.00% | 1.00 | 达标 |
| h +1 档（放宽）h=.50 | 0.577 | 1.39 | **否** | **61.44%** | 0.25 | **超档：误判不达标** |
| h −1 档（加细）h=.20 | 0.231 | 3.46 | 是 | 0.00% | **1.562** | **超档：节点 +56.2% > 50%** |

### 超档处方

- **h = 0.50 档**：可表达条件 h/cosθ < d/2 被破坏。处方 h < d·cosθ/2 = **0.346 m**；
  兼顾节点预算取 h = 0.30 m（N/N₀ = 0.69，d/h_eff = 2.31 > 2），或直接沿用文档 0.25 m。
- **h = 0.20 档**：误判为零但节点超支。处方 h ≥ 0.204 m；取 **h = 0.21 m**
  （N/N₀ = 1.417 ≤ 1.5，d/h = 3.81 仍 > 2）。
- **坡度余量**：h = 0.25 保持可表达的最大坡度 θ_max = arccos(2h/d) = **51.3°**，
  40° 档通过；若未来坡度参数超过 51.3°，必须按 h < d·cosθ/2 同步加细网格。

## 7. 假设与局限

- 一维缝模型忽略缝的弯曲与拐角；二维下判据应改为腐蚀后可走域的连通性检验。
- 整体误判率依赖缝宽分布假设 U[0, 2d]，换分布只改 `ensemble_error` 的积分权重，
  口径 A 的结论（h < d/2）与分布无关。
- 节点数只计平面格点，未计 A* 开放表/闭合表的常数因子与缓存效应。
- x > d/h > 0.5 的非工程区间不做分段闭式，统一用确定性积分（`_quadrature`）画曲线尾部。
