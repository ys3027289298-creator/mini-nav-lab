# 灰度实验：传送门冷却对平均寻路耗时的影响判定

10% 服务器开启传送门冷却（处理组 T），其余维持原样（对照组 C），两组平均寻路
耗时相差约 20%。本实验回答：**这个差异是冷却带来的，还是噪声？需要多少样本、
用什么灰度比例才能把二者分开？**

## 复现方式

```bash
# 1. 实测三种请求的耗时分布：6 轮独立测量（不同种子），每轮 4000 次/类，
#    三类请求在每轮内随机交错；池化后每类 24000 个样本
cd bench && make run
# 2. 校准模型、反解样本量、抽样判定、蒙特卡洛验证（纯标准库，可 -I 运行）
cd ../analysis && python3 -I analyze.py
# 3. 出图（明暗两套，表格孪生 CSV 在 results/figures/）
python3 make_charts.py
```

产物：`bench/results/r*/times_*.csv`（分轮）、`bench/results/times_*.csv`（池化）、
`results/analysis.json`、`results/figures/`。固定随机种子，可完全复现。

## 1. 冷却模型与耗时差的期望表达式

记单次请求的来源与成本（均为 24000 次池化实测，单位 ns）：

| 符号 | 含义 | 实测均值 | 实测方差 |
|---|---|---|---|
| μ_C | 对照组：每次都跑完整 A* | 1445.8 | 2.99×10⁶ |
| μ_m | 处理组首次请求：缓存未命中 + A* + 写入 | 1505.1 | 2.92×10⁶ |
| μ_h | 处理组重复请求：缓存命中，只做哈希查表 | 73.1 | 1.43×10⁵ |
| p | 请求是「冷却窗口内重复请求」的概率 | 由观测校准 | — |

- 对照组期望：`E[X_C] = μ_C`
- 处理组期望（伯努利混合）：`E[X_T] = (1−p)·μ_m + p·μ_h`
- **耗时差（定义为对照组减处理组，正值=变快）**：

```
Δ(p) = E[X_C] − E[X_T] = μ_C − μ_m + p·(μ_m − μ_h)
```

**符号证明（冷却只会让期望下降，不会上升）：**

1. 结构上 μ_m = μ_C +（查表未命中 + 写入）的额外开销，实测 μ_m − μ_C =
   +59.3 ns > 0（随机交错测量，无顺序偏差）；
2. μ_m − μ_h = 1432.0 ns > 0（未命中路径里包含完整 A*，命中路径没有）；
3. 因此 Δ 对 p 严格递增，且 Δ(0) = μ_C − μ_m = −59.3 ns（全是首次请求时，
   冷却只增加一点查表/写入开销），Δ(1) = μ_C − μ_h = +1372.7 ns。
   只要重复请求占比足够高，Δ 必为正；冷却的作用方向单一，**不存在让期望
   上升的机制**。

## 2. 用观测到的 20% 反解重复率 p

现场观测 Δ/μ_C ≈ 0.20，代入精确方程

```
μ_C − [(1−p)·μ_m + p·μ_h] = 0.20·μ_C
⇒ p* = (μ_m − 0.80·μ_C) / (μ_m − μ_h) = 0.2433
```

即约 **24.3% 的请求是冷却窗口内的重复请求**（脚本含断言，校准后理论相对降幅
严格等于 0.2000）。校准点上：μ_T = 1156.7 ns，Δ = 289.2 ns，σ²_T = 2.62×10⁶。
混合方差按精确二阶矩 `E[X²] − E[X]²` 计算，包含组内异质性，不是两个方差的
简单加权平均。

## 3. 反解样本量：差值超过 2 倍标准误才算显著

灰度比例为 g 时，总样本 N 中 n_T = gN、n_C = (1−g)N。两独立样本均值差的标准误

```
SE(D̂) = sqrt( σ²_T/(gN) + σ²_C/((1−g)N) )
```

要求 `Δ ≥ z·SE`（z = 2），解出

```
N*(g) = z²/Δ² · ( σ²_T/g + σ²_C/(1−g) )
```

**当前 g = 10% 下：N* ≈ 1,412 条**（处理组 141 + 对照组 1,271）。
2 倍标准误边界只对应约 62% 功效（差值恰好等于 2SE 时，抽样噪声左右结果）；
要 80% 功效需把 z 换成 2 + 0.8416 ≈ 2.84，得 **N80 ≈ 2,851 条**
（处理组 285 + 对照组 2,566）。

## 4. 灰度比例的取舍：两条曲线定比例

见 `figures/fig1_canary_tradeoff_*.png`（上下两个面板共用横轴，无双 Y 轴）：

| g | N*（2SE 边界） | N80（80% 功效） | 影响面 |
|---|---|---|---|
| 5% | 2,657 | 5,364 | 5% |
| **10%** | **1,412** | **2,851** | **10%** |
| 20% | 805 | 1,626 | 20% |
| 30% | 622 | 1,256 | 30% |
| 40% | 552 | 1,114 | 40% |
| 50% | 537 | 1,084 | 50% |

N*(g) 在 g 很小时随 1/g 陡峭下降（处理组样本是瓶颈），g 超过 ~30% 后趋于
平缓；影响面随 g 线性增长。**10% → 20% 把所需样本量砍掉约 43%，而影响面
翻倍；30% 以后继续加灰度，样本量收益很小却要承担更大的爆炸半径。** 要更快
结论，20% 是性价比拐点；若优先安全，维持 10% 但把窗口攒到 N80。

## 5. 各抽一份样本：实测差值、标准误与结论

在 g = 10%、N80 窗口（处理组 286、对照组 2,574）各抽一份样本：

| 指标 | 值 |
|---|---|
| 处理组均值 μ̂_T | 1155.9 ns |
| 对照组均值 μ̂_C | 1434.2 ns |
| 实测差值 D̂ = μ̂_C − μ̂_T | **+278.3 ns**（处理组更快，相对降幅 19.4%） |
| 标准误 SE | **115.9 ns** |
| z = D̂ / SE | **2.401** |
| 2SE 置信区间 | **[+46.5, +510.0] ns，下沿 > 0** |
| 结论 | **显著（significant）** |

点估计方向与冷却机制的理论方向一致，量级与理论 Δ = 289.2 ns 吻合，且 2 倍
标准误区间不含 0，**可以判定两组约 20% 的差异不是纯噪声，冷却确实降低了
平均寻路耗时**。

蒙特卡洛（10,000 次重复实验）交叉验证：同一设计下差值的经验标准误 100.2 ns，
与解析值 101.6 ns 吻合；在 N80 窗口正确判定「显著」的概率为 80–81%。窗口规模
与拒绝率（`fig3_power_curve`）：

| 窗口 | 总样本 | 蒙特卡洛拒绝率 |
|---|---|---|
| N*/2 | 710 | 0.41 |
| N*（2SE 边界） | 1,420 | 0.62 |
| N80 | 2,860 | 0.80 |
| 2×N80 | 5,720 | 0.93 |

## 6. 结论、对 p 的敏感性，与测量稳健性

**结论：当前 10% 灰度、N80 窗口下，实测差值 +278.3 ns、SE 115.9 ns、
z = 2.40、置信区间 [46, 510] 不含 0，判定为「显著」——差异由冷却带来，
不是噪声。** 但效应量不算很大（区间下沿仅 +46 ns），且 80% 功效意味着同样
设计下仍有约 19–20% 的有效抽样会落在「不足以判定」；若希望结论更稳，把窗口
扩到 2×N80（约 5,700 条）可把功效提到 93%。

结论依赖重复率 p，敏感性分析：

| p | 预期相对降幅 | N*（g=10%） | N80（g=10%） |
|---|---|---|---|
| 0.10 | 5.8% | 17,946 | 36,228 |
| 0.20 | 15.7% | 2,345 | 4,733 |
| **0.243（校准值）** | **20.0%** | **1,413** | **2,852** |
| 0.50 | 45.4% | 220 | 445 |

若真实重复率只有 10%，20% 的观测差值不可能由冷却单独解释，需排查两组的其他
差异（地图结构、负载、时段）。建议上线时直接埋点统计冷却命中率，用实测 p
替换校准值后重跑 `analyze.py`。

**测量稳健性（为何要 6 轮池化，以及结论的可复现性）：** 单次 4000 样本的运行
会被操作系统调度级离群点（个别 9 万–39 万 ns 的长尾）主导二阶矩，单轮方差
跨轮波动很大（缓存命中类的方差极差近 200 倍），但均值稳定（完整 A* 跨轮
变异系数仅 3.6%、未命中 3.2%）。6 轮独立测量池化到 24000 样本后分布矩估计
稳定。我们做了两次完整的「6 轮 + 全分析」独立复现，关键结论高度一致：

| 指标 | 第一次复现 | 第二次复现（当前工件） |
|---|---|---|
| 校准 p* | 0.241 | 0.243 |
| N* / N80 | 1,646 / 3,324 | 1,412 / 2,851 |
| 单样本 z | 2.385 | 2.401 |
| 判定 | 显著 | 显著 |
| N80 蒙特卡洛功效 | 0.81 | 0.81 |

绝对样本量随机器长尾在 ~1,400–1,650（N*）之间浮动，但**两次的 z 都稳定在
2.4 左右、判定都是显著**，结论不依赖某一次运行。每轮均值与方差记录在
`analysis.json` 的 `cross_round_stability`。

## 方法学备注

- 基准测量三种请求**每轮内随机交错**（Fisher–Yates 洗牌），消除 CPU 预热/分支
  预测的顺序偏差；`clock_gettime` 自身开销（约 21–32 ns）已逐轮从中位数标定
  并扣除。
- 6 轮使用不同随机种子独立测量后池化，专门用于稳定重尾分布的方差估计；不做
  离群点删除。
- 处理组方差用伯努利混合的精确二阶矩，包含组内异质性。
- 判定规则严格按题设 `|D̂| > 2·SE`（方向已由机制证明锁定为 D ≥ 0）；报告同时
  给出 80% 功效设计，避免把 ~60% 功效的边界样本量误当稳妥方案。
