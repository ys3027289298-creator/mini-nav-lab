# worstcase

构造让 A* 开放表膨胀的最坏情况地图，并用带微扰的估值函数压回去。
`make test` 跑自检。

## 膨胀条件

A* 必然扩展所有 f = g+h < C* 的节点；f = C* 的节点扩展多少取决于平局规则。
膨胀的形态：大量节点估值相同且都不超过 C*——

- h 系统性低估（h ≪ h*）：整片区域 f 低于 C*，算法在碰到目标前把它们全部扩展；
- f = C* 的平局平台 + 深度无关的平局规则：开放表沿平台横向铺开。

扩展数由区域规模决定，与路径长度脱钩。

## 地图 A：comb_trap（长廊死胡同）

长廊 L=60，两侧每 s=2 列挂深 d=6 的死胡同；终点藏在廊尾墙后，唯一通路从
顶部绕行，C* = L+2d+6 = 78。每个死胡同入口的估值都是 64（程序打印验证全部
相同），分支最深处 f = L+2+2d = 74 < C*，算法被迫逐个试探全部死胡同。

扩展数表达式：E = L + 2d·nb + (2d+7)，nb = ⌊(L−3)/s⌋+1 ≈ L/s，即

    E ≈ L·(1 + 2d/s) = L + N_de·d     （N_de = 2L/s 为死胡同数）

d 与 L 同阶时 E ≈ L·N_de，随地图尺寸平方增长。实测 E(ε=0) = 426 = 自由格数−1，
与模型 L(1+2d/s) = 420 吻合。

长宽比上限：要求 E ≤ W·H/2，反解

    L ≤ (W·H/2 − (2d+7)) / (1 + 2d/s)

本图 W=68, H=20：L_max ≈ 94，L=60 通过。若 s=1（每列都挂死胡同），同样网格
L_max 缩到约 51。

## 地图 B：plateau（对角开阔地）

64×64 空场地对角寻路：每个节点 f = 126，整张图是一个平局平台。浅层优先的
平局规则下扩展 4095 个节点（全图），加任意小微扰后降到 126（路径长）。

## 地图 C：folded_tunnel（折叠隧道）

短路由（绕块，52）必须爬升 h，长路由（蛇形隧道）h 平滑；目标在只从短路由
一侧进入的口袋里（否则长路由波前会从目标侧反向更新目标的 g，次优现象消失）。
ε 超过约 1.4 后隧道波前先送达目标，返回次优解（实测 60，ratio 1.154）——
这是"最优性保持"曲线的拐点。

## 微扰强度取舍

f' = g + (1+ε)·h。扫描 ε 得到两条曲线：

- 扩展数：comb 426→110，plateau 4095→126，tunnel 511→~180，随 ε 增大下降；
- 最优性：comb、plateau 全程保持（路径唯一 / 贪心直下必最优），tunnel 在
  ε ∈ (1.0, 1.5] 处破坏。

取保持所有地图最优的最大 ε，得 ε* = 1.0。理论上 ε < 1/C* 是保持最优的充分
条件（本例 1/52 ≈ 0.02），实测拐点远在 1.4 附近——充分条件太保守，微扰强度
应以实测两条曲线为准。

## 验收

ε* = 1.0 下三张图各跑一次：comb 156 < 680，plateau 126 < 2048，
tunnel 460 < 1555，均低于全图节点数的一半，且路径保持最优。
ε = 0 时 plateau 扩展 4095 ≥ 2048 超半——地图特征：64×64 全自由格、
对角起终点、全图 f 同值。
