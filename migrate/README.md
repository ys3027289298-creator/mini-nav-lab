# migrate

旧格子坐标接口（整数格号）迁移到新浮点世界坐标接口时，**按格心还是按格角**
做坐标转换对路径长度的影响、1% 预算下的段数上限、以及迁移成本取舍。

`make test` 跑 C 自检并产出三份 CSV；`make curves` 额外画取舍曲线（明暗两套 PNG）。

## 1. 两种转换的表达式

格宽记为 `s`，格号为整数向量 `i=(i_x, i_y)`：

| 约定 | 表达式 | 含义 |
|---|---|---|
| 按格心 | `P_c(i) = (i + 0.5) · s` | 新接口参考点取格子中心 |
| 按格角 | `P_k(i) = i · s` | 沿用旧接口的格子左下角 |

两者之差对每个格号都是固定的半格平移：

```
P_c(i) - P_k(i) = 0.5 · s          （与 i 无关）
```

## 2. 对路径长度的影响

一条路径有 `N` 段、`N+1` 个航点 `P_0 … P_N`，长度
`L = Σ_{i=1..N} ‖P_i - P_{i-1}‖`。

### 2.1 统一约定（全程格心或全程格角）——长度零偏差

整条路径用同一约定时，半格平移在相邻航点求差时相消：

```
(P_i + 0.5s) - (P_{i-1} + 0.5s) = P_i - P_{i-1}
⇒ L_corner ≡ L_center，相对偏差 = 0
```

本模块三档路径实测 `rel_corner_pct = 0.000000`，由自检
`*_uniform_corner_matches_center=1` 守住。**统一按格角本身不会产生长度偏差**，
3% 的差异只可能来自新旧约定混用（部分航点重算、部分没重算）。

### 2.2 混用约定（部分迁移）——偏差真实存在

设第 `i` 个航点的锚点偏移为 `e_i ∈ {0, 0.5s}`（格心=0，未迁移的格角=0.5s）。
第 `i` 段的长度只由两端锚点之差 `e_i - e_{i-1}` 决定：

- 两端都迁移或都没迁移：`e_i = e_{i-1}`，该段误差为 0（望远镜抵消）；
- 只有一端没迁移（**切换边**）：`e_i - e_{i-1}` 是沿某一轴的 `±0.5s`。
  四邻域路径里这条边本身沿另一条轴，故切换边长度只可能取两个值：
  - 错锚偏移与该边方向垂直（普通内部转弯）：`√(1²+0.5²)·s = √0.5·s ≈ 0.7071·s`，
    单段误差 `−0.2929·s`；
  - 错锚航点在该边方向上也偏半格（起终点边界段）：`√(1.5²+0.5²)·s = √2.5·s ≈ 1.5811·s`，
    单段误差 `+0.5811·s`。T1/T3 的最劣段 seg 0 就是这一类。

即**误差只产生在锚点切换处**；直段内部无论多长都完全抵消。

题给的保守累积模型（每段都按半格上界计）：

```
ΔL ≤ N · 0.5 · s
相对偏差上界  δ ≤ N · 0.5 · s / L
```

> 注意在四邻域网格上 `L = N·s`，代入后该上界恒等于 **50%**，与 N 无关。
> 它是「每段独立、误差不抵消」的最坏情形，说明这个模型极其保守：
> 实际误差只在锚点切换处（错锚的转弯点、未迁移的起终点）产生，直段内部全部抵消。

更贴合实测的**紧上界**：一条部分迁移路径只有起点、终点两个错锚航点时，
每个错点的位移向量模长 ≤ `s/√2`（0.5s 沿两轴）：

```
ΔL ≤ 2 · s/√2 = √2 · s
δ_tight ≤ √2 · s / L
```

若路径内部还有 `q` 个彼此隔离的错锚转弯点（被至少一个已迁移航点隔开，
误差不跨段抵消），每多一个就新增两条切换边、贡献一份正的净误差，
总偏差随 `q` 单调累积。之字形路径（`L=24`）实测：

| 错锚转弯点 q | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| 实测相对偏差 | 0.00% | 0.30% | 0.62% | 1.04% |
| 对应绝对 ΔL | 0 | 0.0722 | 0.1494 | 0.2484 |

每份增量（0.072 / 0.077 / 0.099）不相等，因为单个转弯点的贡献取决于
它两侧直段的长度方向；但增量恒为正、偏差随错锚点数量累积的结论稳定，
由自检 `rollout_monotone_non_decreasing=1` 守住。

## 3. 反解允许的最大段数（预算 1%）

令相对偏差不超过预算 `ε = 1%`，分别反解 `N_max`：

**保守模型（题给，每段半格）：**

```
ε ≥ N · 0.5 · s / L
⇒ N_max = ⌊ ε · L / (0.5 · s) ⌋ = ⌊ 0.02 · L / s ⌋
```

**紧模型（两个错锚端点，与 N 无关、只与 L 有关）：**

```
ε ≥ √2 · s / L
⇒ 长度门槛 L ≥ √2 · s / ε ≈ 141.4 · s
⇒ N_max = ⌊ ε · L / (√2 · s) ⌋
```

参考表（`s=1, ε=1%`，程序 `-- nmax_reference` 输出）：

| L | N_max（保守/题给） | N_max（紧模型） |
|---|---|---|
| 10 | 0 | 0 |
| 20 | 0 | 0 |
| 40 | 0 | 0 |
| 100 | 2 | 0 |

`s=1` 时两个公式给出的 N_max 都很小，这正是保守模型的信号：1% 预算下，
**只要混用约定就几乎没有段数余量**，结论指向「要么全量迁到格心、要么别动」。
把 `s` 调小（更细的网格，`L/s` 变大）N_max 才会放开。

## 4. 取舍：两条曲线定方案

- **偏差曲线**（`curves_light.png` 左、中面板）：混用约定的偏差随错锚航点/
  转弯点增多而上升，1% 红线是硬预算。
- **成本曲线**（右面板）：按格角迁移成本恒为 0（无需重算既有航点），
  按格心成本为 `N+1` 个航点的全量重算，随段数线性增长。

决策规则：

1. 路径段数在 `N_max` 以内、且能保证**全路径统一约定** → 按格角可接受（零成本、零偏差）；
2. 超出 `N_max`，或迁移必须分批、存在新旧约定混用窗口 → **改用格心转换并全量重算**，
   重算成本是一次性的，长度偏差归零；
3. 任何情况下禁止混锚上线：偏差全部产生在锚点切换处。

## 5. 三档路径实测验收（预算 1%）

网格 16×12，四邻域 A*，`s=1`。数据见 `results.csv`，逐段见 `segments.csv`。

| 档位 | 起→终格号 | 段数 N | 转弯数 | L（格心） | 混锚偏差 | 统一格角偏差 | 闸门 |
|---|---|---|---|---|---|---|---|
| T1 short  | (0,0)→(4,11)  | 15 | 2  | 15 | **1.9216%** | 0.0000% | **FAIL** |
| T2 medium | (0,0)→(15,11) | 40 | 6  | 40 | 0.7206% | 0.0000% | PASS |
| T3 long   | (0,0)→(15,11) | 28 | 13 | 28 | **1.0294%** | 0.0000% | **FAIL** |

超差档位的最劣段（程序 `worst_segment:` 行与 `segments.csv` 一致）：

- **T1**：seg 0，起点格 `(0,0)` → 终点格 `(1,0)`；参考长度 `1.0000`，混锚长度
  `1.5811`，绝对误差 `0.5811`。
- **T3**：seg 0，起点格 `(0,0)` → 终点格 `(1,0)`；参考长度 `1.0000`，混锚长度
  `1.5811`，绝对误差 `0.5811`。

注意 T3 段数（28）比 T2（40）少却超差：混锚的绝对误差由错锚点数量决定而非段数，
T3 转弯更密集、路径更短（分母 L 小），相对偏差反而更大。这与「段数越多偏差越大」
的保守模型并不矛盾——保守模型是上界，实测由真实错锚点驱动。
