# degrade

寻路五条错误码的降级链。`make test` 跑自检（含五条错误各一次触发、门槛诊断、400 次随机请求的策略扫描）。

## 记号

- 起点 `S=(sx,sy)`、目标 `G=(gx,gy)`，曼哈顿距离 `D0 = |sx-gx|+|sy-gy|`
- 完整最短路 `P*`，长度 `L*`（格数，步数为 `L*-1`）
- 降级返回路径 `P_d`，长度 `L_d`，终点 `E_d`
- 靠近比例（玩家实际缩短的目标距离份额）：

  `rho = 1 - d(E_d, G) / D0`，裁剪到 `[0,1]`
- 步行份额（题目定义的「能走多远」）：`q = L_d / D0`，单调最短路上 `rho = q`

验收门槛：`rho >= 0.5`（玩家至少靠近目标一半距离）。低于门槛的降级不交付，回退明确失败。

## 五条降级的返回值表达式

| 错误码 | 触发条件 | 降级动作 | 返回值表达式 |
|---|---|---|---|
| `E_TIMEOUT` | 节点预算 `B` 内未抵达目标 | 保留预算内 `h=|dx|+|dy|` 最小的已展开节点 `v_best` 的父链 | `P_d = parent_chain(v_best)`，`L_d = g(v_best)+1`，`v_best = argmin h(v)` |
| `E_UNREACHABLE` | 开放集耗尽，目标不在 `S` 的连通分量 | BFS 求全可达集 `R(S)`，取距原目标最近的可达点 `t`，重跑 A* | `t = argmin_{v∈R(S)} d(v,G)`，`P_d = A*(S,t)`，`L_d = dist_R(S,t)+1` |
| `E_BAD_START` | `S` 不可走 | BFS 推到最近可走格 `S'`（同距取索引最小），再搜索 | `S' = argmin_{v walkable} d(v,S)`，`P_d = A*(S',G)` |
| `E_BAD_GOAL` | `G` 不可走 | 同理把目标推到最近可走格 `G'` | `G' = argmin_{v walkable} d(v,G)`，`P_d = A*(S,G')` |
| `E_TOO_LONG` | `L* > cap` | 保留完整最短路的前 `cap` 格 | `P_d = P*[0..cap-1]`，`L_d = cap` |

地图上没有任何可走格时降级本身不可能，返回 `E_FAIL`（扫描中占 0.3%）。

## 反解：允许截断的最大比例

截断比例 `r = (L* - L_d) / (L* - 1)`（按步数计）。截断点沿最短路距目标还剩

`d(E_d,G) = D0 - (L_d - 1)`

（最短路前缀每走一步到目标的距离减一）。代入门槛：

```
rho = (L_d - 1) / D0 >= 0.5
=> L_d >= 0.5 D0 + 1
=> r_max = (L* - 1 - ceil(0.5 D0)) / (L* - 1)
```

即最多砍掉约一半的目标距离。例：`D0=8`、绕路后 `L*=21`（步数 20），`r_max = (20-4)/20 = 0.80`——
绕路场景下即使砍掉 80% 的步数，终点仍在半程点上，因为被砍的主要是绕向远端的那段。
自检的 `too_long` 用例：cap=19、`r=0.10`，实测 `rho=0.750`。

## 策略：两条曲线定门槛

400 次随机请求（障碍密度 15–25%，固定种子），扫描接受门槛 θ：

| θ | 有效路径率 E(θ) | 误导率 M(θ) |
|---|---|---|
| 0.0（最激进） | 0.998 | 0.036 |
| 0.1–0.3 | 0.988 | 0.012 |
| 0.4 | 0.985 | 0.006 |
| **0.5（选定）** | **0.983** | **0.000** |
| 0.6 | 0.975 | 0.000 |
| 0.8 | 0.943 | 0.000 |
| 1.0（最保守） | 0.782 | 0.000 |

- 有效路径率随 θ 单调下降，误导率单调下降；
- θ=0.5 处误导归零，而有效率仅比全量交付低 1.5 个百分点；继续收紧到 1.0 才明显掉有效率。
- 结论：**激进降级（θ<0.5）用 3.6% 的误导换 1.5% 的有效率，不划算；工作点取 θ=0.5**，
  即五条降级照常计算，但 `rho<0.5` 的结果拒绝交付、回退明确失败。曲线可视化见
  `../artifacts/degrade_strategy.html`。

## 五条触发构造与自检结果

| 用例 | 构造 | 降级后终点 | rho | 门槛 |
|---|---|---|---|---|
| `bad_start` | 起点 (2,2) 设为阻挡 | (10,2) | 1.000 | 通过 |
| `bad_goal` | 目标 (12,5) 设为阻挡 | (12,4) | 0.900 | 通过 |
| `unreachable` | x=9 整列墙，目标在另一侧 | (8,6) | 0.600 | 通过 |
| `timeout` | 空地预算 26，距目标差 1 次展开 | (2,11) | 0.565 | 通过 |
| `too_long` | x=6 列墙仅 y=0 留口，cap=19 | (10,4) | 0.750 | 通过 |

另含三个**故意不达标**的诊断用例，用于验证 harness 能报出是哪条降级没生效：

- `timeout_starved`（预算 3）：rho=0.077，超时降级生效但深度不足 → 拒绝；
- `too_long_aggressive`（cap=12，截断点还在绕路腿上）：rho=0.000 → 截断降级未达标；
- `unreachable_far`（墙在 x=5，最近可达点离目标仍远）：rho=0.214 → 最近可达点降级未达标。
