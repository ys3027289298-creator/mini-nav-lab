# belt

传送带强制位移与路径跟随的冲突建模、停留时限反解与策略选择。`make test` 跑自检，`make csv` 输出两条曲线的原始数据。

## 推导

角色站在传送带上时，每帧叠加两个位移：

- 路径推进：`u * dt`（沿当前路径）
- 传送带推移：`v_belt * dt`（强制）

平行于路径的分量被路径推进吸收，只有垂直分量 `v_perp` 产生偏离，逐帧线性累积：

```
d_{k+1} = d_k + v_perp * dt        =>        d(t) = v_perp * t
```

用偏离预算 `d(t) <= r`（r 为角色半径）反解最长停留时间：

```
t_max = r / v_perp                 （传送带与路径平行时 v_perp = 0，t_max = ∞）
```

超过 `t_max` 后两档策略：

| 策略 | 行为 | 代价 |
|---|---|---|
| `follow` 不暂停 | 偏离触达 r 即从当前位置重算路径，偏离归零重新累积 | 偏离有界，重算次数随停留时间线性增长 |
| `pause` 暂停跟随 | 触达 r 的同一帧挂起跟随，由传送带带出，出口处重算一次 | 只重算一次，但放弃原路线 |

修正在越界的同一帧生效（frame-atomic），所以相对**当前有效路径**的偏离始终不超过 r；`pause` 下相对原路线的整体搬运偏移（carry）仅作观测，出口重算时被新路径吸收。

## 验收

三档传送速度 `v = 0.2 / 1.0 / 3.0` 各跑一次，选中策略必须同时满足：

1. 最大偏离 `<= r`（0.5）
2. 重算次数 `<= 传送期间帧数 / 10`

慢档两条件都不触发，选 follow；中档 follow 的重算仍在预算内，选 follow；快档 follow 超出预算，切换 pause（出口一次重算）。
