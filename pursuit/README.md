# pursuit

移动目标追击与预判，`make test` 跑自检。

## 三条评审意见的落地

设角色位置 `p`、速度 `u`、半径 `r`；目标位置 `q`、速度 `v`、速率 `w=|v|`；
角色到目标距离 `D`，单位接近向量 `e=(q-p)/D`，预判时长 `T`。

1. **基本预判式（原来完全没有预判）**

   ```
   q_pred = q + v·T
   ```

   角色朝预判点而非目标当前位置运动；`T=0` 即旧的纯追踪，必然滞后。

2. **预判时长与距离的关系（原来写死）**

   ```
   T_lead = clamp(D / u, T_min, T_max)
   ```

   距离远则预判长、近则短，`D/u` 正是以角色速度闭合该距离所需时间；
   clamp 只做上下界，不再有写死的预判距离常量。

3. **目标反向的单独判据**

   目标速度与接近向量夹角 θ 满足

   ```
   cos θ = v·e / |v| < 0   ⇔   θ > 90°
   ```

   定义对头接近速度 `s = max(0, -v·e)`（θ≤90° 时为 0）。预判点沿接近轴
   朝角色推进 `s·T`，越过距离 D 即冲到角色身后，前冲量 `s·T − D`。
   要求过冲不超过预算 `2r`，反解出必须缩短预判的条件：

   ```
   s·T − D ≤ 2r   ⇔   T ≤ (D + 2r)/s = T_safe
   ```

   最终时长取两者较小值：

   ```
   T = clamp(min(T_lead, T_safe), T_min, T_max)
   ```

## 取舍与验收

预判长则对匀速目标准、对反向目标过冲，短则滞后。自检里用固定评估口径扫出
两条曲线：滞后 L(T) 随 T 下降、过冲 O(T) 随 T 上升，在 `O ≤ 2r` 预算内取
L 最小的 T；距离律 `D/u` 在中距离正好落在该区间，远距才升到 T_max。

三档目标速度（3、5、7）各跑一次：

- 接触后跟踪包络（滞后距离）≤ 角色半径 `r`；
- 目标反向后的过冲距离 ≤ `2r`；
- 接触帧不晚于纯追踪（T=0）。

旧的写死时长 `T=1` 作为回归基线保留在自检中，其跟踪包络明显超出 `r`。
