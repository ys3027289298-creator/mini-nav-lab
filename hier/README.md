# hier

两层分层 A*：块级先找粗路径，再只在粗路径走廊内做格级细化。
`make test` 构建并跑自检 + 三档距离基准；`make chart` 刷新分析数据与图表。

## 1. 节点数表达式与反解

世界边长 W = 2048，块边长 c（格），块网格每边 n = W/c 个块。
设全图最优路径长 L（格），路径途经的块数约为 L/c（每块贡献 c 格路径）。

| 层次 | 需要展开的节点数 |
|---|---|
| 块级（粗） | n² = (W/c)² |
| 块内细化（细） | 途经块数 × 每块格数 ≈ (L/c)·c² = L·c |

分层总节点数：

```
n_hier(c) = (W/c)² + L·c
```

不分层时整张图展开：

```
n_full = W²
```

两者之比：

```
r(c) = n_hier / n_full = 1/c² + L·c/W²
```

这就是块尺寸的取舍式：第一项随 c 增大而下降（块大→块级节点少），
第二项随 c 线性上升（块大→每块细化面积大、块内变慢）。

### 反解 1：多大才划算（break-even，r < 1）

纯几何模型（k=1）令 r(c) = 1，代入 W = 2048、最长查询 L = 3601：

```
1/c² + 3601·c/2048² = 1
```

c=2 时左侧 0.250 + 0.0017 ≈ 0.252 已小于 1，即几何上只要分块就划算；
真正的门槛不是"要不要分层"，而是下面的最优点。计入走廊外扩的拟合
系数 k 后（见下节），分析脚本在远距档数值解出的 break-even 为 c≈4，
与该结论一致。

### 反解 2：最优点（dr/dc = 0）

```
dr/dc = -2/c³ + L/W² = 0
⇒ c* = (2W²/L)^(1/3)
```

| 距离档 | L（格） | 几何最优 c* | 含义 |
|---|---|---|---|
| 近距 | 451 | 26.6 | 短路径：细层占比小，倾向小块 |
| 中距 | 1403 | 18.2 | |
| 远距 | 3601 | 13.3 | 长路径：细层面积主导，最优 c 反而更小 |

直觉相反但式子说了算：路径越长，L·c 这项越大，
压制它需要更小的 c；块大只在路径短时占优。

### 有效系数 k（走廊外扩的代价）

实现中走廊向外扩 MARGIN=2 个块以保证细化可走通，细层实际触达
k·L·c 个节点（k≥1，由实测最小二乘拟合，见 `tools/analyze.py`）：

```
r(c) = 1/c² + k·L·c/W²，  c* = (2W²/(kL))^(1/3)
```

实测 k：近距 0.148、中距 0.014、远距 0.334；拟合后的连续 c* 为
50.1 / 75.6 / 19.1，与离散候选上的实测最低点（32 / 256 / 64）同区间。

## 2. 两条曲线怎么定块尺寸

- **成本曲线**（`chart.html` 图一）：实测节点占比随 c 呈 U 形，
  与解析模型同形。左支是块级项 1/c²，右支是细化项 kLc/W²。
- **质量曲线**（图二）：路径长度相对全图 A* 的增幅。
  本配置 18 组查询全部 0.000%（细化在走廊内仍跑完整 A*，
  只是搜索域受限；走廊含最优路径时结果即最优）。在更密的障碍图上
  大 c 会出现 1%~3% 增幅（早期种子实验中观测到 2.6% / 1.6%），
  所以质量约束随 c 单调收紧，与成本曲线的右支共同排除大块。

**选型规则**：在质量曲线 ≤5% 的 c 集合里，取成本曲线最低点。
本机数据下三档统一推荐 **c = 32~64**：
c=32 对近/中距最优（0.23% / 0.18%），c=64 对远距最优（1.82%），
且两档在另一档上都不超过 4.1%。

## 3. 正确性设计（三个必须处理的坑）

1. **粗边不等于能过**。"块内有任意空格"不保证相邻两块间存在
   跨越共享边的开放格对。预处理时逐边扫描边界，得到
   `hpass/vpass` 通过表（HPA* entrance 测试），粗 A* 只走可行边。
2. **可行边不保证块内连通**。每条边的入口各自存在，但入口之间
   可能被障碍围住。两道保险：
   - 走廊外扩 MARGIN=2 块，给块内绕行留空间（本基准 18/18 成功）；
   - 仍失败时回退一次全图 A*，并把真实路径经过的块并入走廊，
     后续查询可复用（CSV `fallback` 列记录，本基准全为 0）。
3. **粗层失败即不可达**。全高密封墙会让边界通过表断开，
   粗 A* 返回 -1，与全图 A* 的结论一致（自检覆盖）。

## 5. 复现

```sh
make test          # 自检 + 基准，输出 results/bench.csv
python3 -I tools/analyze.py   # 门限校验、k 拟合、c* 反解、图表数据
# 浏览器打开 chart.html
```

耗时口径：`full_ms/hier_ms` 为单次查询墙钟时间（含粗层与细化，
不含一次性的块图预处理 `preprocess_ms`）。节点数是主指标，
墙钟时间受堆实现与缓存影响，仅作参考。
