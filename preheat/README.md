# preheat

按区域停留占比加权的卡顿指标，以及可见性预热的区域数选择。`make test` 跑自检。

## 指标

设区域 `i` 停留占比 `p_i`（Σp_i = 1）、未预热单次寻路卡顿 `l_i`（ms）：

- 简单平均（现状，主城卡顿被野外空闲稀释）：`L̄ = (1/n)·Σ_i l_i`
- 加权卡顿指标：`L_w = Σ_i p_i·l_i`
- 预热 k 个区域（按停留降序）的覆盖比例：`C(k) = Σ_{i=1..k} p_(i)`
- 反解最少区域数：`k_min = min { k : C(k) ≥ 0.80 }`
- 约束：残余加权卡顿 `L_w(k) < 0.60·L̄`，预存路径内存 `M(k) ≤ 700 MB`

## 三档停留分布的自检结论

| 分布 | 三主城覆盖 | k_min（占 8 区） | 内存 | 是否可行 |
|---|---|---|---|---|
| 集中档 80/20 | 80.0% | 3（37.5%） | 650 MB | 可行 |
| 均衡档 80/20 | 80.0% | 3（37.5%） | 650 MB | 可行 |
| 分散档 | 72.0% | 4（50.0%） | 740 MB | **不可行，差 W1（超内存 40 MB）** |

三档在各自 k_min 处残余卡顿最高仅 7.95 ms，均远低于六成平均 34.12 ms；唯一缺口是分散档纳入 W1 后内存超上限。
